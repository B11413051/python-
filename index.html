Python 類別與物件：從設計藍圖到實體房子

寫程式時，我們常常需要描述「同一類事物」的共同結構，並依此建立許多各自獨立的個體。透過建築藍圖與房子的對照，快速掌握 class、 __init__ 與 self。

01. 觀念圖解

設計藍圖 vs. 實體房子

先選好規格再點擊「依藍圖蓋房子」，觀察多個物件如何各自保有獨立屬性。

Class 類別

建築設計藍圖 (House)

1 份定義

藍圖本身還不能住人，它只規定好每一棟房子都必須擁有「牆壁顏色」與「樓層數」，以及可以執行的動作（例如開門或改漆顏色）。

class House: BLUEPRINT SPEC
設定新物件的初始參數 (__init__)
牆壁顏色 (color)
樓層數 (floors)

即將執行：House(color="海藍", floors=2)

Object 物件（實例）

蓋出來的實體房子們

目前已建立 2 / 3 棟

每一棟房子都是根據同一張 House 藍圖建出的獨立個體。試著點擊單一房子的「開門 / 關門」或「換漆顏色」，看看其他房子會不會受到影響。

關鍵體會：Class 只有一份，Object 可以有無限多個 獨立記憶體 · 互不干擾

02. 程式碼範例

認識 __init__ 與 self

house_blueprint.py 
1# 1. 定義類別 (設計藍圖)：類別名稱習慣用大寫開頭
2class House:
3    # __init__ 是建構子：每當「蓋新房子」時會自動執行
4    def __init__(self, color, floors):
5        # self 代表「正在被建立的那一棟房子自己」
6        self.color = color      # 設定這棟房子的牆壁顏色
7        self.floors = floors    # 設定這棟房子的樓層數
8
9    # 定義方法 (房子能做的動作)，第一個參數一樣要寫 self
10    def introduce(self):
11        print(f"這是一棟 {self.color}、共 {self.floors} 層的房子。")
12
13# 2. 依藍圖建立物件 (實體化)：產生兩棟互不干擾的房子
14my_house = House("海藍色", 2)
15friend_house = House("暖磚紅", 3)
16
17# 3. 呼叫方法：Python 會自動把 my_house 傳給 self
18my_house.introduce()      # 輸出：這是一棟 海藍色、共 2 層的房子。
19friend_house.introduce()  # 輸出：這是一棟 暖磚紅、共 3 層的房子。

__init__(self, ...)

初始化方法

名稱前後各有兩條底線，負責在物件剛誕生時「裝潢基本配備」。呼叫 House("海藍色", 2) 的瞬間，Python 就會自動執行它。

self 參數

指向「這一個物件」

因為同一個類別可以造出很多房子，方法需要知道「現在是誰在呼叫我」。當執行 my_house.introduce() 時，self 就代表 my_house 本身。

my_house = House(...)

實體化（Instantiation）

不需要自己傳入 self，只要把 color 與 floors 放進括號裡，就能產出真正佔有記憶體空間的物件。
